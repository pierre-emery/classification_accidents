# Projet dans le cadre du cours STT3795
## Analyse, regroupement et classification des collisions routières à Montréal

# Pour travailler sur le projet ou rerun les notebooks il faut simplement installer sur Miniconda ou Anaconda sur votre machine

## Installation

1. Clonez le dépôt :
```bash
   git clone 
   cd 
```

2. Créez et activez l'environnement conda :
```bash
   conda env create --file environment.yml
   conda activate accidents-env
   pip install -e .
```

3. Lancez JupyterLab :
```bash
   jupyter lab
```
